# 技術記事の主張と根拠を照合する

読者の選択を変え得る一文から調べる。特に「安全」「必ず」「影響しない」といった断定、倍率、障害原因の説明に注目する。

- 数値は元の記録まで戻り、比較対象、単位、分母、集計方法を確かめる。応答が返った時点と処理が完了した時点など、測定の始点・終点が本文の表現に合っているかを見る。
- 動作の説明は、記事が扱うバージョンと設定に対応する実装や一次資料を参照する。仕様上の保証、今回観測した結果、著者の推定を区別する。
- 結論の適用範囲を確かめる。たとえばプロセス強制終了を10回試した結果は、その条件での観測として書ける。ホスト電源断について述べるには別の根拠が要る。

指摘ごとに「該当する一文」「根拠と、そこから言える範囲」「著者の意図を保った修正文」を示す。根拠は該当行や表に直接結び付ける。資料が足りない場合は、手元で確認できた範囲と、判断に必要な記録を具体的に示す。
